CH 01

Introduction to Java

📌 Theory — Key Points

  • Java is an Object-Oriented Programming (OOP) language.
  • Java programs are compiled into Java Bytecode (.class files).
  • Bytecode is executed by the JVM (Java Virtual Machine) — an interpreter.
  • Compiled code is platform-independent (Write Once, Run Anywhere).
  • JVM → part of JRE → part of JDK (JDK is the full development kit).
  • Two types of Java programs: Stand-alone Applications and Web Applets.
  • Stand-alone apps run on a local computer. Applets run in a browser via internet.
  • Flow: Test.java → Compiler → Test.class (bytecode) → JVM Interpreter → Output

Running a Java Program

  • Step 1 — Compile: javac HelloWorld.java
  • Step 2 — Run: java HelloWorld

💻 Code — Hello World

HelloWorld.java 
public class HelloWorld {     public static void main(String[] args) {         System.out.println("Hello"); // prints Hello to console     } }
Hello
Every Java application must have one class with a main() method as the entry point.

🔄 Type Casting

  • Java performs automatic type conversion when there is no risk of data loss.
  • Two types of casting:
  • Widening (Automatic): Smaller type → Larger type. No data loss.
    byte → short → int → long → float → double
  • Narrowing (Manual/Explicit): Larger type → Smaller type. May lose data.
    Syntax: (targetType) value
Widening.java 
int myInt = 9; double myDouble = myInt; // automatic System.out.println(myInt);    // 9 System.out.println(myDouble); // 9.0
Narrowing.java 
double myDouble = 9.78; int myInt = (int) myDouble; // explicit System.out.println(myDouble); // 9.78 System.out.println(myInt);    // 9
Widening = safe (automatic). Narrowing = risky (requires explicit cast).

String in Java

📌 Theory — Key Points

  • String is a class (not a primitive) that stores a collection of characters.
  • Two ways to declare: String s = new String("Hello"); OR String s = "Hello";
  • Strings cannot be compared with == or != — use .equals() method.
  • String concatenation: use + operator. If expression starts with a String, the next argument is converted to String.
  • s.length() — returns number of characters in the string.
  • s.charAt(i) — returns the character at index i.
  • s1.equals(s2) — returns true if strings are equal.
  • s.concat("text") — joins two strings together.

💻 Code — String Operations

StringOps.java 
public class StringOps {     public static void main(String[] args) {         String s1 = "Hello";         String s2 = "Hello";          // Length         System.out.println(s1.length());         // 5          // Character at index         System.out.println(s1.charAt(1));        // e          // Comparison (use equals, NOT ==)         System.out.println(s1.equals(s2));      // true         System.out.println(s2.equals("Hi"));   // false          // Concatenation         String str = "Hello";         String s = str.concat(" World");         System.out.println(s);                  // Hello World          // Using + operator         System.out.println("Sum = " + (5 + 3));  // Sum = 8     } }

Arrays

📌 Theory — Key Points

  • An array is a fundamental, linear data structure storing items at contiguous memory locations.
  • It is a collection of elements with the same data type.
  • Arrays exist in 1D (single) and multi-dimensional (2D, 3D...) forms.
  • Each location in an array has a numerical index starting from 0.
  • Difference: Array index = label for the element. Memory address = starting address of free memory.
  • Basic operations: Traversal, Insertion, Deletion, Search, Update.

Declaration Syntax (2 forms)

  • dataType arrayName[size]; e.g. int numbers[3];
  • dataType[] arrayName = new dataType[size]; e.g. int A = new int[3];
  • int[] age = {12, 4, 5, 2, 5}; — initialize with values directly.
Array length: use arrayName.length e.g. int size = a.length;

💻 1D Array — Declare, Init, Traverse

Array1D.java 
class Main {     public static void main(String[] args) {          // Method 1: Declare and initialize separately         int[] age = new int[5];         age[0] = 12;         age[1] = 10;         age[4] = 13;          // Method 2: Initialize with values         int[] age2 = {12, 9, 5, 2, 5};          // Traversal using for loop         System.out.println("Array traversal:");         for (int i = 0; i < age2.length; i++) {             System.out.println("Element: " + age2[i]);         }          // Enhanced for loop (for-each)         for (int a : age2) {             System.out.print(a + " ");         }     } }

💻 Array Sorting (Bubble Sort)

NumberSorting.java 
class NumberSorting {     public static void main(String[] args) {         int[] numbers = {55, 40, 80, 65, 71};         int n = numbers.length;          System.out.println("Given list:");         for (int i = 0; i < n; i++)             System.out.print("  " + numbers[i]);          // Bubble sort         for (int i = 0; i < n; i++) {             for (int j = i + 1; j < n; j++) {                 if (numbers[i] > numbers[j]) {                     int temp = numbers[i];                     numbers[i] = numbers[j];                     numbers[j] = temp;                 }             }         }          System.out.println("\nSorted list:");         for (int i = 0; i < n; i++)             System.out.print("  " + numbers[i]);     } }

OOP Concepts — Overview

📌 Theory — OOP Principles

  • Java is a general-purpose, Object-Oriented language.
  • Objects are the basic runtime entities. They represent persons, places, tables, or any item a program handles.
  • Each object contains Data (fields) + Code (methods) to manipulate data.
  • Objects interact by sending messages to one another.
  • 3 Pillars of OOP: Encapsulation, Inheritance, Polymorphism.

Data Encapsulation

  • The wrapping of data and methods into a single unit (class).
  • Data is not accessible to the outside world; only the wrapped methods can access it.
  • Makes objects behave like "black boxes" — information hiding.

Abstraction

  • Representing essential features without including background details.
  • Classes encapsulate all essential properties and methods of objects to be created.
CH 10

Classes & Objects

📌 Theory — Key Points

  • A class is a blueprint / user-defined data type. A object is an instance of a class.
  • Class declaration: class ClassName { [fields] [methods] }
  • Fields (Instance Variables): Data placed inside class body. Created when an object is instantiated. Each object has its OWN copy.
  • Methods: Functions declared inside the class. They manipulate the data in the class.
  • Generic method form: returnType methodName(parameterList) { method body }
  • Creating an object: Use new keyword → ClassName objName = new ClassName();
  • Accessing members: objectName.variableName = value; and objectName.methodName(params);
  • this keyword — refers to the current object whose variable is being called.

Static Members

  • A static member is common to ALL objects — it belongs to the CLASS, not to individual objects.
  • Static variables and methods can be accessed without creating an object.
  • Declared with: static int count;

Constructors & Method Overloading

📌 Theory — Constructors

  • A constructor is a special method that initializes an object when it is created.
  • Constructor has the same name as the class.
  • Constructor has no return type (not even void).
  • Called automatically when an object is created with new.

Method Overloading

  • In Java, it is possible to create methods with same name but different parameters.
  • The difference may be in the number or types of arguments.
  • Each parameter set must be unique.
  • Used when objects need to perform similar tasks but with different inputs.

Inheritance

📌 Theory — Key Points

  • Inheritance = the process by which objects of one class acquire the properties of objects of another class.
  • The principle: each derived class shares common characteristics with the class from which it is derived.
  • Inheritance promotes code reuse — reuse something that already exists rather than creating it again.
  • Old (parent) class = Super class / Base class / Parent class.
  • New (child) class = Sub class / Derived class / Child class.
  • The subclass inherits ALL variables and methods of parent classes.
  • Keyword: extends — class B extends A { ... }
  • super() — used to pass values to the super (parent) class constructor.

Types of Inheritance

  • Single Inheritance: One super class, one sub class.
  • Multiple Inheritance: Several super classes, one sub class.
  • Hierarchical Inheritance: One super class, many sub classes.
  • Multilevel Inheritance: Derived class is used as super class for another derived class — builds a chain (A→B→C).
Java does NOT support multiple inheritance with classes (to avoid ambiguity). Use Interfaces instead.

💻 Code — Single Inheritance

SingleInheritance.java 
class Room {     int length;     int breadth;     Room(int x, int y) { length = x; breadth = y; }     int area() { return length * breadth; } }  class BedRoom extends Room {       // BedRoom inherits Room     int height;     BedRoom(int x, int y, int z) {         super(x, y);                  // pass values to parent constructor         height = z;     }     int volume() { return length * breadth * height; } }  class InheritTest {     public static void main(String[] args) {         BedRoom room1 = new BedRoom(14, 12, 10);         System.out.println(room1.area());    // uses parent method         System.out.println(room1.volume());  // uses child method     } }
area = 168  |  volume = 1680

CH 13

Polymorphism — Overloading & Overriding

📌 Theory

  • Polymorphism = the ability to take more than one form.
  • An operation may behave differently in different situations. The behaviour depends on the type of data used.
  • Two types: Method Overloading (compile-time) and Method Overriding (runtime).

Method Overloading

  • Multiple methods with same name but different parameter lists in the SAME class.
  • Difference can be in number or type of arguments.

Method Overriding

  • A method in the child class has the same name and same parameters as in the parent class.
  • It happens in Inheritance — the child overrides the parent method.
  • When overridden method is called, child's version executes, not parent's.

💻 Code — Method Overriding

Overriding.java 
class A {                          // parent class     int a, b;     void display() {         System.out.println(a);         System.out.println(b);     } }  class B extends A {              // child class — overrides display()     int c;     void display() {         System.out.println(a);   // inherited field         System.out.println(b);   // inherited field         System.out.println(c);   // own field     } }
Overloading = same class, different params. Overriding = child class, same method signature.

Interface

📌 Theory — Key Points

  • An interface is a kind of class that defines only abstract methods and final fields.
  • Unlike a class, an interface cannot be instantiated (no objects).
  • Used to achieve multiple inheritance and complete abstraction in Java.

Key Characteristics of Interface

  • a) It is a collection of method signatures and constant values.
  • b) All variables in an interface are implicitly public, static, and final.
  • c) All methods are implicitly public and abstract.
  • d) They provide a contract for classes — any class that implements an interface must provide code for ALL its declared methods.
  • Keyword: implements — class MyClass implements MyInterface { ... }
Interface → Used for multiple inheritance. Abstract class → Used for partial abstraction.

💻 Code — Interface Example

InterfaceDemo.java 
interface Shape {     void draw();   // abstract — no body }  class Circle implements Shape {     public void draw() {         System.out.println("Drawing Circle");     } }  class Box implements Shape {     public void draw() {         System.out.println("Drawing Box");     } }  class Triangle implements Shape {     public void draw() {         System.out.println("Drawing Triangle");     } }  class Main {     public static void main(String[] args) {         Shape s1 = new Circle();         Shape s2 = new Box();         s1.draw();         s2.draw();     } }
Drawing Circle  |  Drawing Box
